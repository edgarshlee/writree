# v0.1.3 — Workspace restore and file rename

- Reopen the most recently used workspace when Writree starts
- Show its Markdown file tree immediately without asking for the folder again
- Cache the recent workspace locally, render the tree before recovery/Git work finishes, and avoid spawning Git while opening
- Rename Markdown files from the tree action, right-click menu, or `F2`
- Keep open tabs and the active document attached to the renamed path
- Refuse unsafe paths and existing destination names without overwriting data

Renames remain ordinary working-tree changes and are never committed automatically.
