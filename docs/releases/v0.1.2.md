# v0.1.2 — Visual editor mode fix

- Allow Milkdown-supported `<br>`, `<br/>`, and `<br />` tags in visual editing mode
- Keep unsupported raw HTML such as `<details>` in source mode to protect the original text
- Add unit and click-through E2E regression coverage for mode switching

This patch fixes documents being unnecessarily locked in source mode when they contain a line-break tag.
