# v0.3.0 — Optional account sync

- GitHub OAuth one-time desktop callback and rotating refresh tokens
- Java 21/Spring Boot API with PostgreSQL and Flyway
- Workspace opt-in cursor sync with optimistic base revisions
- Conflict copies, recoverable remote deletion, 100 revisions, 30-day tombstones
- Docker Compose demo and Testcontainers coverage

Sync remains optional. Local editing and Git continue to work with an empty
server URL.
